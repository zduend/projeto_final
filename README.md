# Sistema de Análise de Vendas

## Sobre o projeto

Projeto final do curso de Desenvolvedor Python, voltado à análise de 50 mil registros de vendas de uma empresa varejista, entre 2021 e 2023.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Análises realizadas

- Limpeza e tratamento dos dados;
- Faturamento bruto e líquido;
- Desempenho de produtos, categorias e vendedores;
- Sazonalidade das vendas;
- Formas de pagamento;
- Desempenho por região;
- Estudo aplicado e recomendação estratégica.

## Principais resultados

- **Faturamento líquido:** R$ 110.636.684,76.
- **Pedidos concluídos:** 24.305.
- **Registros após tratamento:** 49.701.
- **Gráficos desenvolvidos:** 10.

## Como executar

Instale as bibliotecas necessárias com `pip install pandas matplotlib jupyter`.

Abra o arquivo `resolucao/projeto_final.ipynb` e execute as células na sequência.
